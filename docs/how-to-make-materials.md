# How to make your own materials for the Swipe mod
Hi! In this short tutorial, you'll learn how to create custom materials for CarX Drift Racing Online, so you can apply them to your car. A guide on how to create custom liveries with UV mapping is available in this post: [coming soon.](https://github.com/Jeefrect/Swiper)
## Unity install
First, [download the required](https://unity.com/releases/editor/whats-new/2023.2.20f1) version of Unity. CarX Drift Racing Online currently uses version 2023.2.20f1, so we'll download that specific engine version.

> If you already have this version of Unity, for example, you already have the SDK for creating kinomod objects, then you do not need to download it again.

Now create a new Unity project using this version of the engine or just use an already created Unity project.
### Asset bundle builder Install
The easiest way to create your own asset bundles (files that will contain your assets) is to simply install the [AssetBundles Browser](https://github.com/Unity-Technologies/AssetBundles-Browser) extension package.

After installation, a button for asset building will appear in your project (Windows -> Asset bundle browser)
